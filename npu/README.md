# npu backend

windows 11 arm64 / snapdragon x elite.

install from msys2:

```bash
curl -fsSL https://raw.githubusercontent.com/Kooraseru/discourse-community-notes/gemini-nano/npu/install.sh | bash
```

the installer sets up the local npu backend and starts it at login.

endpoint: `http://127.0.0.1:18181/v1`
